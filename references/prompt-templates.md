# 通用提示词模板

本文件只维护任务输入；执行、比较和报告规则分别引用对应文档，不在提示词中另写一套。替换尖括号内容后使用，不保存特定批次清单。下面四个模板分别独立使用。

## 持续批量渲染并比较已有 SDK

```text
使用 davinci-tcflash-eval，读取 SKILL.md，并按入口读取批次执行、SDK 比较和报告规范。

DRP：<绝对路径列表或目录>
已有 SDK 基准（只读）：<根目录，以及已知的项目对应关系>
输出根目录：<绝对路径>
本批例外或补充参数：<没有则写“使用 Skill 默认策略”>

目标是比较已有外部 SDK 与插件经 Resolve 导出的解码像素是否严格一致。渲染前按 SDK 规格准备对应导出设置；帧映射按比较规则核实。

请持续负责准备、渲染、监测、诊断恢复、比较和交付。可执行项直接执行，不能执行的说明原因并处理其他项；宿主未知状态先按恢复规则处理。交付统一总报告、每项详细报告和最终状态统计。
```

## 仅渲染压力测试

```text
使用 davinci-tcflash-eval，读取 SKILL.md，并按入口读取批次执行和报告规范。本批只验证导入、插件识别与渲染，不进行 SDK 比较。

DRP：<绝对路径列表或目录>
导出方案：<已验证的 render_preset，或明确的 format/codec；仅明确接受当前导出状态时填写 imported_current>
输出根目录：<绝对路径>
本批例外或补充参数：<没有则写“使用 Skill 默认策略”>

请持续执行和监测，按恢复规则处理异常，交付统一总报告、每项详细报告及渲染结果统计。
```

## 恢复本批

```text
使用 davinci-tcflash-eval，继续批次：<batch 绝对路径>。
读取 SKILL.md、批次执行说明及本批 manifest/报告，按续跑规则检查控制权和宿主状态，继续未完成项。必要重试记录原因和新 attempt。更新同一份报告并跟进到本轮结束或有证据的阻断。
```

## 只查状态

```text
使用 davinci-tcflash-eval，查询批次：<batch 绝对路径>。
按报告规范只读取本批报告、状态快照与日志，说明当前项、进度、已记录耗时、错误、快照是否过期及报告路径。本次只读文件，不启动执行器或操作 Resolve。
```
